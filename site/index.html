// project

google-cloud-terraform

A private GKE Autopilot platform with five Python microservices, built with Terraform and designed to be temporary: an environment comes up from nothing with one command, gets verified end to end, and is deleted completely.

  • Private nodes, no public IP on the database, and no route to the internet from Pods.
  • Workload Identity everywhere and no service account keys; generated secrets never reach Terraform state.
  • GitHub Actions deploys through Workload Identity Federation, while Terraform runs by hand, so CI holds no infrastructure credentials.
  • The dev, test and prod environments have been run successfully.
